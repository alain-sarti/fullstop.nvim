# Anchor at the statement-container boundary — not at the child of the tree root

`locate` rises from the cursor's node to the **innermost ancestor whose parent is a statement container** (`program`, `statement_block`, `class_body`, `switch_body`, `switch_case`, `switch_default`), and treats a cursor that lands *on* such a container as "no statement here" (→ Advance). The rule it replaces — rise while `parent ~= root`, i.e. stop at the child of the tree root — is correct only for top-level statements: for anything nested it climbed past the statement onto the whole enclosing `function` / `if` / `class`, so `analyze` balanced the construct's entire text and `apply` spliced closers at its last line. The two rules coincide at top level, which is why the whole suite passed while essentially all real code was mangled. (Issue 01 words the rule as the *outermost* such node; innermost is what it means and what the ticket's own two-levels-deep case requires — the outermost reading is the bug.)

The container list is the load-bearing part, and it is a **whitelist of statement holders, not of block-ish nodes**: `object`, `interface_body`, `arguments` and friends are deliberately absent, so a statement wrapping an object literal or an argument list still anchors to the whole statement ("the cursor selects, never bounds"). Rising past a container-less chain to a parentless node still returns nil, which keeps the old guard against anchors from an injected tree: no grammar injected into a TypeScript/TSX buffer roots at `program` (`jsdoc` roots at `document`, `regex` at `pattern`, `css` at `stylesheet`), and the filetype guard means no other buffer reaches `locate`. In a hypothetical TS-in-TS injection the guard would let the anchor through — the reason it holds is the grammar set, not the rule itself.

Treesitter remains trusted for **position only** (the spec's decision, restated in `locate`'s header): the anchor is usually an `ERROR` node, and every meaning decision stays in `analyze` on raw text. The known residual mis-anchoring is a broken statement whose own delimiters **swallow the enclosing block's brace**, leaving no statement node to anchor to: an unclosed `{` or `${` eats the `}` below it, and a tail after the block (`} catch`, `} while`, `})`) collapses the whole construct into one `ERROR`. The anchor is then the construct — or nil, when that `ERROR` is the tree root, which reads as Advance. Ranking anchor candidates inside a swallowing `ERROR` (a delimiter-based fallback ladder) is a separate ticket; ADR-0001 keeps the wrong verdict revertible in a single `u` until then, and `tests/test_locate.lua` pins the two shapes so the ladder has something to flip.
